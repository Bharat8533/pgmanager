# StayManage (PGManager)

Centralized PG & Hostel Management SaaS Platform.

## Project Structure

- **`Frontend/`**: Complete Next.js 16 (App Router) + TypeScript + Tailwind CSS application.
  - Owners Panel: Properties, Rooms, Bookings & Residents, Expenses, Rent & Payments.
  - CA-ready Excel reporting and ledger analytics.
- **`Backend/`**: Future backend services and APIs.

## Running the Application

### Option 1: Run directly from Root
```bash
npm run dev
```

### Option 2: Run from the Frontend folder
```bash
cd Frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
